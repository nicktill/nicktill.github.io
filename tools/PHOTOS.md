## The original seven

`scene-3`, `scene-7`, `scene-8`, `scene-15`, `scene-17`, `scene-19` and
`scene-21` were already in the project and their provenance is not recorded.
They are not Nick's own photographs. Before this site goes public those
should either be traced to a licence that permits the use, or replaced with
more CC0 files from the same search. `tools/` has no script for that search;
it was a Wikimedia Commons API query for `intitle:Unsplash` plus landscape
terms, filtered to files at least 2400px wide.
